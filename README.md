# УЧАСТОК — Осень. 1996.

Тактический симулятор начальника отделения милиции. Вид от первого лица, графика в духе PS1/PS2, реальное время с паузой.

## Как играть прямо сейчас
Откройте `dist/index.html` в браузере Chrome (на телефоне — в горизонтальной ориентации). Игра работает целиком из одного файла, интернет не нужен. Сохранения хранятся в браузере.

## Как собрать APK

### Вариант 1. Android Studio (на компьютере)
1. Установите Android Studio.
2. Откройте папку `android/` как проект.
3. Меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk` — перекиньте на телефон и установите (разрешите установку из неизвестных источников).

Перед сборкой Gradle сам копирует свежий `dist/index.html` в приложение.

### Вариант 2. Без компьютера — через GitHub
1. Создайте репозиторий на github.com и загрузите туда содержимое архива.
2. Во вкладке **Actions** запустится сборка «Сборка APK» (файл `.github/workflows/build-apk.yml`).
3. Через 3–5 минут скачайте APK из раздела **Artifacts** этой сборки.

## Управление
**Телефон:** левая половина экрана — ходьба (оттяните палец дальше — бег), правая — обзор, короткий тап по предмету или человеку — действие. Кнопки: ДЕЙСТВИЕ, ПМ (достать/убрать пистолет), ОГОНЬ, ПРИСЕСТЬ, ФОНАРЬ, БЕГ.
**Компьютер:** WASD — ходьба, мышь — обзор (клик для захвата), E — действие, R — пистолет, ЛКМ — огонь, C — присесть, Shift — бег, L — фонарь, Пробел — пауза, 1/2/3 — скорость времени, Tab — рация, N — блокнот, Esc — меню.

## Где что на участке
- **Дежурная часть:** карта города (наряды в город), схема участка (оборона), рация (журнал эфира), сводка, мониторы.
- **Кабинет начальника:** шкаф с личными делами, телефон снабжения, сейф.
- **Оружейная:** выдача снаряжения.
- **ИВС:** задержанные и допросы (также кабинет оперов).
- **Комната отдыха:** телевизор с новостями, чайник.
- **Генераторная:** электрощит — поднять рубильник, если вырубили свет.

## Для разработки
- `index.html` + `src/` — исходники (ES-модули, без библиотек). Локально: `node tools/serve.mjs . 8765` и откройте `http://localhost:8765/`.
- `node tools/build.mjs` — сборка в `dist/index.html` (нужен esbuild).
- `docs/CONTRACTS.md` — устройство подсистем.
